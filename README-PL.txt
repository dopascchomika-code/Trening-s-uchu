TRENING INTERWAŁÓW — instrukcja

Zawartość:
- index.html — aplikacja
- manifest.webmanifest — ustawienia aplikacji webowej
- sw.js — pamięć podręczna do działania offline
- icons/ — ikony

UŻYCIE NA IPHONIE:
1. Umieść zawartość ZIP na hostingu HTTPS (np. GitHub Pages).
2. Otwórz adres aplikacji w Safari na iPhonie i poczekaj na załadowanie.
3. Naciśnij Udostępnij → Dodaj do ekranu początkowego → Dodaj.
4. Uruchom z ikony i dotknij „Odtwórz dźwięki”, aby aktywować audio.
5. Otwórz aplikację jeszcze raz, a potem sprawdź działanie w trybie samolotowym.

Po pierwszym załadowaniu pliki aplikacji są buforowane do pracy offline. Dźwięki są generowane lokalnie w przeglądarce; nie wymaga to pobierania nagrań ani wysyłania danych.
